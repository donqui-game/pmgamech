# 도시 생존 시뮬레이터

프로젝트 문의 도시를 배경으로 한 비공식 팬메이드 텍스트·전투 시뮬레이션 프로토타입입니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더 안의 파일과 폴더를 저장소 최상위(root)에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택합니다.
5. Branch는 `main`, 폴더는 `/ (root)`로 지정하고 저장합니다.
6. 잠시 기다린 뒤 표시되는 Pages 주소로 접속합니다.

## 파일 구조

```text
city_survival_sim/
├─ index.html
├─ README.md
├─ css/
│  └─ style.css
├─ js/
│  ├─ data.js
│  └─ game.js
└─ data/
   ├─ ranks.json
   ├─ events.json
   ├─ skills.json
   ├─ weapons.json
   └─ quests.json
```

## 현재 구현

- 출생 판정: 평범한 시민 90%, 소지 출신 가문 7%, 혈귀 3%
- 구역별 시작 생명력·안·연줄
- 기본 능력치와 핵심 수치
- 진로 선택: 해결사, 엄지, 검지, 중지, 약지, 소지, 기업(L사/W사)
- 평판·계급·승급시험 화면
- 의뢰 게시판과 턴제 전투
- 무기 구매, 장착, 스킬 슬롯
- 치료소, 소지 훈련, 약지 화풍, 검지 지령, 중지 앙갚음 장부, 혈귀 혈기 관리
- localStorage 저장 및 불러오기
- PC·모바일 반응형 화면

## 저장 관련 주의

현재 저장은 접속한 브라우저의 `localStorage`에만 기록됩니다. 다른 기기와 공유되지 않으며, 브라우저 데이터 삭제 시 사라질 수 있습니다. GitHub Pages만으로 계정 간 온라인 저장이나 서버 멀티플레이는 제공되지 않습니다.

## 밸런스 및 미완성

설계서에서 임시로 표시한 확률·가격·보상·전투 수치는 테스트용으로 적용했습니다. 기업별 고유 혜택, 모든 손가락 세부 이벤트, 완전한 스킬 효과, 세밀한 전투 합 규칙 등은 후속 업데이트 대상입니다.

원작의 이미지·대사·게임 파일을 포함하지 않습니다. 모든 화면 문구와 UI는 자체 제작한 프로토타입입니다.
